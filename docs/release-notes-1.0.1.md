# Notion Writer v1.0.1

Notionへの書き込みと下書きの保護を強化しました。

- ページ作成の応答と本文の追記直前に、保存先のDB IDとデータソースIDを照合します。作成したページが移動・削除された場合は追記を止めます。
- 画像のアップロード後に保存先を再確認します。データソースが変わっていた場合はページ作成を止めます。
- 保存結果が不明な場合は下書きを保持し、自動再送を止めます。作成を確認できたページは、途中で失敗した場合もNotionで確認できます。
- 同じ下書きフォルダを複数のアプリプロセスが同時に使用するのを防ぎます。

配布アプリはAppleシリコン搭載MacのmacOS 13以降向けです。ZIP内のアプリはローカル署名です。Developer ID署名とAppleの公証はありません。
