# Notion Writer v1.0.0

初回リリースです。macOSのメニューバーからNotionへすばやくメモを保存できます。

- タイトルに長文、改行、空行を入力して保存
- Tabと検索で複数のタグを選択。クリックでの連続選択にも対応
- 展開式の本文エディタでMarkdownを整形・編集。スラッシュコマンド、表、本文内の画像挿入に対応
- ローカル下書きの復元と、送信失敗時の入力内容の保持
- 保存先のDBとデータソースを登録時と送信前に照合
- APIトークンをmacOSのキーチェーンに保管

配布アプリはAppleシリコン搭載MacのmacOS 13以降向けです。最初の接続手順はREADMEを参照してください。

ZIP内のアプリはローカル署名です。Developer ID署名とAppleの公証はありません。
