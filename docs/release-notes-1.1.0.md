# Notion Writer v1.1.0

Web記事とブックマークを、メモやタグと一緒にNotionへ保存できます。

- **ブックマーク**。本文にWeb URLを貼って「ブックマークを作成」を選ぶと、取得できた記事タイトル、説明、サムネイルをカードで表示します。Notionへはブックマークとして保存します。
- **記事の取り込み**。「記事を取り込む」を選ぶと、元記事のブックマークを先頭に置き、1行空けて公開本文を追加します。改行と空行を保持し、取得できた画像とリンクを元の順序で取り込みます。ブラウザで選択した記事も、クリップボードにHTMLがあれば書式や画像を取り込めます。
- **画像の追加**。本文を閉じたまま挿入順をサムネイルで確認できます。本文を開いているときはカーソル位置に画像を追加できます。5MB以上の画像がある場合は添付欄に警告を表示します。
- **送信と入力のクリア**。入力画面の下段にボタンを追加しました。送信は `⌘ Enter`、入力をクリアする初期キーは `⌘⌫` です。呼び出しとクリアのキーは「設定」→「一般」で変更できます。URL欄の左余白もほかのプロパティに揃えました。

配布ZIPはAppleシリコン搭載MacのmacOS 13以降向けです。アプリはローカル署名です。Developer ID署名とAppleの公証はありません。
