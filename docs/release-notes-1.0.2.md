# Notion Writer v1.0.2

Notionへの接続案内を見直しました。初回接続と、同じ保存先を別のMacで使うときの手順を設定画面とREADMEに掲載しています。

- 初回セットアップでは、Notionの「コンテンツへのアクセス」から保存先のデータベース名を検索して選びます。新規メモの保存には「コンテンツを読み取る」と「コンテンツを挿入」を使います。
- 2台目のMacでは、同じデータベースのリンクと既存のAPIトークンを登録する手順から進められます。
- 接続確認が成功すると、プロパティとタグを同期したことが設定画面に表示されます。アクセスに失敗した場合は、確認する設定項目を案内します。

配布ZIPはAppleシリコン搭載MacのmacOS 13以降向けです。アプリはローカル署名です。Developer ID署名とAppleの公証はありません。
