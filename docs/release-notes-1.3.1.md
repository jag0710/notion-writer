# Notion Writer v1.3.1

## 最近の項目

- プロパティ一覧の先頭に「最近の項目」を独立した1行として配置しました。ここから、送信時のタグとURLをまとめて入れ直せます。
- 履歴内のタグにNotionの色を反映しました。選択中も薄い青の背景に濃い文字で表示します。

## 記事・対話・全文の取り込み

- **記事を取り込む**。元記事のURLはURLプロパティに記録します。本文は記事の内容から始まり、本文中のURLはクリックできるリンクとして送ります。
- **対話を取り込む・全文を取り込む**。空欄のタイトルは、共有対話の題名または取り込んだ文章の先頭から補います。保存先の「雑記」に既存の「AI」タグがあれば追加します。
- **カードや段組みの表示**。対話本文に混ざる装飾タグを取り除き、カードの見出しと値を読みやすい箇条書きにします。参照先を取得できた引用はリンクに変換します。

配布ZIPはAppleシリコン搭載MacのmacOS 13以降向けです。アプリはローカル署名です。Developer ID署名とAppleの公証はありません。
