# Notion Writer v1.2.0

## 対話と文章の取り込み

- **対話を取り込む…**。ChatGPTの共有URLから、発言順・改行・書式を保ちながら本文に追記します。元の会話URLはURLプロパティに入ります。アプリから開けない非公開対話は、ログイン済みのブラウザでコピーして「全文を取り込む…」に貼り付けられます。
- **Google AI Studio**。URLを入力し、初回にGoogle Driveへ保存された元の対話ファイルを選びます。「あなた」「Google AI Studio」の発言を順番に取り込み、思考行は省きます。ファイル接続は「設定」→「対話取り込み」で確認・解除できます。
- **全文を取り込む…**。コピーした対話や文章を本文に追記します。発言の区切りが明確な対話は「あなた」「AI」で整理し、Google検索のAIモードではコピーに含まれる出典の文字も残します。

## Notionへの送信

- **バックグラウンド送信**。`⌘ Enter` で下書きをMacに保存すると入力画面が閉じ、Notionへの送信が続きます。成功時はメニューバーにチェックマークが短時間表示されます。
- **送信履歴と再送**。「設定」→「履歴」で内容と送信結果を確認できます。保存上限は5・10・20・50・100件から選べます（初期値は5件）。未送信の内容は元の保存先へ再送できます。
- **ブックマークの表示**。「設定」→「一般」で「URLだけ貼る」と「サムネイル付きカード」を切り替えられます。カードの画像を取得・添付できない場合は、通常のブックマークとして保存します。
- 設定の「Notion」を「Notionへの接続」に改名しました。

配布ZIPはAppleシリコン搭載MacのmacOS 13以降向けです。アプリはローカル署名です。Developer ID署名とAppleの公証はありません。
