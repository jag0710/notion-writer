# Notion Writer v1.3.0

## 動画の取り込みと入力操作

- **動画を取り込む**。YouTubeの動画URLを貼ってEnterを押すと、タイトルと元URLを入力します。保存先に「ネット収集情報」のタグ候補があれば追加します。本文はそのままです。
- **最近の入力**。タグ選択の先頭から、送信時のタグとURLをまとめて入れ直せます。保存先ごとに直近10回分をこのMacに保持します。矢印キーとEnter、またはクリックで選べます。
- **プロパティとタイトルの操作**。左右矢印でタイトル入力に戻り、タグ候補は上下矢印で先頭と末尾を行き来できます。日本語変換中に文字が折り返すと、タイトル欄が広がります。

## 記事・対話・全文の取り込み

- **対話を取り込む**。ChatGPTの公開共有URLはそのまま取り込めます。非公開ChatGPTとGoogle AI Studioは、ログイン済みのブラウザで対話を開いてコピーし、Writerに貼り付けると元URLも残せます。
- **全文を取り込む**。発言見出し、段落の間隔、出典の表示を調整しました。Google検索のAIモードをコピーしたときも、文中の出典と出典カードの文字を保持します。
- **記事を取り込む**。元のURLを本文の先頭にプレーンテキストとして追加します。サムネイルカードとその設定を削除しました。
- 設定の「取り込み全般」に対話・記事・全文の設定をまとめました。入力画面では保存先名の表示を外し、「送信」ボタンを横に広げました。

配布ZIPはAppleシリコン搭載MacのmacOS 13以降向けです。アプリはローカル署名です。Developer ID署名とAppleの公証はありません。
