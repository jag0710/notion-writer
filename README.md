# Notion Writer

Notionにメモをすばやく保存するmacOSのメニューバーアプリです。長い文章や空行もタイトルに入力でき、タグ付けから保存までキーボードで操作できます。macOS 13以降に対応します。本リリースの配布アプリはAppleシリコン用です。

## はじめに

配布ZIPのアプリはローカル署名です。Developer ID署名とAppleの公証はありません。macOSのセキュリティ設定によっては、初回起動が制限されることがあります。

1. GitHub ReleasesのZIPを展開し、Notion Writer.appを「アプリケーション」に移動して開きます。
2. [Notionの接続管理](https://app.notion.com/developers/connections)で内部接続を作ります。「コンテンツを読み取る」と「コンテンツを挿入」をオンにし、接続の「設定」からAPIトークンをコピーします。「コンテンツを更新」はオフで使えます。
3. 接続の「コンテンツへのアクセス」→「アクセス権限を編集」を開きます。「ページを検索する」に保存先のデータベース名を入力し、検索結果からデータベース本体を選んで保存します。
4. Notionで保存先のデータベースを開き、右上の「•••」→「リンクをコピー」でリンクを取得します。データソースが複数ある場合は、保存したいビューのリンクを使います。メニューバーの「設定」→「Notionへの接続」でリンクとAPIトークンを入力し、「接続を確認して保存」を押します。表示されたデータベース名を確認し、「保存先に設定」を押します。

2台目のMacで同じ保存先を使うときは、手順4で同じリンクと既存のAPIトークンを登録します。

登録前に操作を試すときは、メニューバーから入力画面を開くとサンプルタグが表示されます。

## 使い方

- `⌘ Space` で入力画面を開閉します。「設定」→「一般」で変更できます。Spotlightと競合する場合は設定画面に案内が出ます。
- `Enter` で改行します。`Tab` でタグ選択を開き、文字入力で検索、上下キーで移動、`Enter` で選択します。クリックでも連続で選択できます。
- 本文は「本文を追加」で展開します。Markdownは整形済みの状態で編集でき、`/` で見出し・箇条書き・グレーの背景などを選べます。
- 「画像を追加」の隣の「記事を取り込む…」を押し、URLを入力して `Enter` で取り込めます。空欄のタイトルは【記事タイトル】の形式で入力され、空欄のURLプロパティには元のURLが入ります。
- 「対話を取り込む…」でChatGPTの閲覧可能な共有URLを入力すると、発言順のまま本文に追記し、URLプロパティに元のURLを入れます。非公開の対話を読み取れないときは、ブラウザで会話をコピーして「全文を取り込む…」を使えます。
- Google AI Studioの対話URLでは、最初にGoogle Driveに保存された元の対話ファイルを選びます。「設定」→「対話取り込み」でファイル接続を確認・解除できます。Googleアカウントへの直接接続は試験版の対象外です。
- 「全文を取り込む…」は、コピーした対話や普通の文章を本文に追記します。発言の境目が明確な対話には「あなた」「AI」の見出しを付けます。
- 本文に単独のWeb URLを貼ったときも、ブックマークの作成、URLのまま貼り付け、記事の取り込みを選べます。取り込んだ記事は元記事のブックマーク、空行、公開本文の順に入り、改行や取得できた画像とリンクを保持します。
- 「画像を追加」、画像の貼り付け、ドラッグ＆ドロップで画像を本文に添付できます。本文を閉じている間は挿入順にサムネイルが並びます。5MB以上の画像が含まれる場合は添付欄に警告が出ます。
- 「送信」または `⌘ Enter` を押すと、下書きをこのMacへ保存して入力画面を閉じ、バックグラウンドでNotionに送信します。成功するとメニューバーに約2.5秒間「✓」が出ます。「!」が出た場合は入力画面や設定の「履歴」で確認できます。
- 「設定」→「履歴」でタイトル・本文などを確認し、未送信の内容を同じ保存先に再送できます。履歴の上部で、保存上限を5・10・20・50・100件から選べます（初期値は5件）。上限を下げると、保存上限を超えた古い履歴を削除します。結果不明のときは、Notionでページの状態を確認してから再送してください。
- 「設定」→「一般」で、Notionに送るブックマークを「URLだけ貼る」か「サムネイル付きカード」から選べます。カードでは、リンク付きタイトル・説明・画像をひとつにまとめます。画像を取得または添付できない場合は、ブックマークとして残ります。
- 「入力をクリア」または `⌘⌫` でタイトル、プロパティ、画像、本文を消去します。キーの組み合わせは「設定」→「一般」で変更できます。
- Macへのログイン時に起動するには、macOSのシステム設定でログイン項目に追加します。

## 通信とローカルデータ

トークンはmacOSのキーチェーンに保存します。下書き、添付画像、プロパティのキャッシュは `~/Library/Application Support/Notion Writer/` に保存します。保存先ごとに下書きとキャッシュを保持します。送信履歴も設定した上限までこのMacに保存します。

接続設定では、指定された保存先のメタデータを読み取ります。書き込み前に保存先とデータソースを再確認します。長い本文は、作成したページの親IDを都度照合してから追記します。保存結果が不明な場合は下書きを保持します。書き込みは新しいページの作成、画像の送信、そのページへの本文追記に限ります。キャッシュが古くなったときの入力画面の表示、設定からの手動同期、保存操作がNotionとの通信を開始します。記事の取り込みやブックマークのプレビューでは、参照先のWebサイトや画像の配信元から公開情報を取得します。

普段使うデータベースに接続する前に、専用の内部接続を用意してアクセス先をそのデータベースに絞り、読み取りと挿入だけを有効にしてください。Notion側に「ページ追加」を条件とするオートメーションがある場合は、実行される処理を確認してください。

## ソースからビルド

Swift 6を含むXcodeまたはCommand Line Toolsが必要です。リポジトリのルートで実行します。

```sh
bash scripts/build.sh
open 'work/Notion Writer.app'
```

検証は通信モックと一時データを使います。

```sh
swift run --scratch-path work/build NotionWriterVerify
bash scripts/verify-app.sh
```

試験版を作るときは `bash scripts/build.sh --trial` を実行します。生成された `work/Notion Writer Trial.app` は正式版と異なるアプリ識別子で動き、下書き、設定、キーチェーンが分かれます。試験版の「設定」→「Notionへの接続」で接続を登録してください。

正式配布用としてビルドするときは `NOTION_WRITER_SIGN_IDENTITY` にDeveloper ID Application証明書の名前を指定します。公証とZIPの作成はAppleの手順に従います。

Notion WriterはNotionの非公式アプリです。このリポジトリにはソフトウェアライセンスを付けていません。
